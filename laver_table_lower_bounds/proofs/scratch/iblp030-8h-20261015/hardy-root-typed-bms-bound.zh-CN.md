## 1. 有限类型与对角线迭代

数值域是整数域，即x>=2。 设X_0由非递减函数f组成，其中f(x)>=x+1。 递归函数X_(r+1)包含保持点序性的函数， 广泛的地图 X_r -> X_r。 因此，在适当的逐点阶数下，结果为T(u)>=u。 元素被累加到最后一个数字输入为x时停止。

对于一个递增序列(u_n)在X_r中，通过选择n=x在FINAL的数值输入来定义其对角线Delta_r(u_n)。在类型0时，

~~~text
Delta_0(u_n)(x)=u_x(x);
~~~

在更高的类型中，

~~~text
Delta_(r+1)(u_n)(v)=Delta_r(u_n(v)).
~~~

n->u_n的逐点单调性确保了Delta_r(u_n)仍然属于X_r。

定义每种类型的x-迭代和x+1-iteration：

~~~text
I_0(T)(x)=T^x(x),         I_0^+(T)(x)=T^(x+1)(x);
I_(r+1)(T)(u)=Delta_r(T^n(u));
I_(r+1)^+(T)(u)=Delta_r(T^(n+1)(u)).
~~~

广泛性使得权力序列不断增加，因此这些都是可以接受的。

对于一个原始-IBLP指数P和基数f，在X_r中定义F_P^(r,f)，在X_r中通过

~~~text
F_empty=f;
F_(Q+1)=I_r(F_Q);
~~~

对于，使用F_P=Delta_r(F_(P[n]))表示非后继者。对于BMS，定义G_M^(r,f)为相同的序列，但在后继者处使用I_r^+，在极限处使用原始的BMS基本序列。r=0条款是通常的数字FGH，分别用x和x+1表示迭代。

这些是建立在先前证明的A/grammar锥体或BMS上的有根递归。源极限对角线是允许的，因为源正的基本项是嵌套的字面前缀，而下面的强前缀不等式使得它们的层次值逐点增加。

## 2. 类型一致前缀和覆盖引理

在每一个有限类型r上，同时的良基归纳法证明：

- G_M^(r,f)位于X_r内，并且单调依赖于f。
- Q  严格 BMS 前缀的 M 意味着

~~~text
G_M^(r,f) >= I_r^+(G_Q^(r,f)) pointwise.           (2.1)
~~~

- A 有限 BMS 下降 M -> Q 使用索引 <=x 之后，任意

固定了更高类型的参数和最终数值输入为x，

~~~text
G_M^(r,f)(...)(x) >= G_Q^(r,f)(...)(x).           (2.2)
~~~

每种类型的证明都是相同的。 迭代比较使用在X_(r-1)上的单调扩展映射。 而Delta仅选择最终的数值输入。 在非后继M中， 每一个正的M[x]都严格扩展了cut(M)。 因此，每一个合适的前缀Q中的M剩余部分适当的前缀M[x]. 在后继时，使用定义的I_r^+。 输入单调性是由嵌套的基本项和较低对象的最终输入单调性所决定的。 这并非一个假设，即任意的序数不等式都意味着FGH不等式。

因此，原始的safe-D任意覆盖定理可以统一地证明：如果 P 在 D 中被标准 BMS M 覆盖，那么

~~~text
F_P^(r,f) <= G_M^(r,f).             (2.3)
~~~

成功抵达目标M， 对每个覆盖的P进行量化。 每一个可接受的f， 以及所有更高的参数。 A源后继节点具有严格前缀目标覆盖，并被(2.1)吸收。 因为源语言使用I_r，目标语言使用I_r^+。 A源非后继O_x使用目标宏指令，仅使用0,1,x-1,0； 它的封面要小得多。 在最后的输入x处应用IH和(2.2)。 在ALL到f范围内进行量化，允许在下一个类型中进行算子迭代。

更明确地说， 固定r，并对TARGET索引进行归纳，归纳声明为：M。 对于每一个由M覆盖的有限源P， 每一个基数 f 在 X_r 中， 每一个较高参数的元组， 以及每一个最终的x>=2， (2.3)在该元组评估后保持有效x. 因此，对于固定的较小目标M，的IH是整体对象点态不等式。 不仅一个事实x. 在源-目标案例中， cut(P)具有固定的前缀覆盖M'<M。 其整体对象IH可以在由迭代产生的每一个中间步骤中被合法使用。 包括在高阶类型中更改的底层函数。 在源限制的情况下， 首先固定元组，最后将x固定。 封面宏指令

然后选择可能依赖于x的较小目标M_x覆盖P[x]. 将已经普遍适用的IH应用于M_x， 仅在固定的元组和点x处进行评估。 然后在那个SAME x处使用<=x-index宏比较(2.2)。 没有任何因素能够体现这种特定于x的比较，或者将其提升为涉及单一选定M_x的统一比较。 由于原始的元组,x是任意的, 最终的完整不等式在文末给出。

## 3. 仅用于BMS的种子操作符

定义类型 r 的实际 A 种子操作符：

~~~text
B_r : X_r -> X_r,       B_r(f)=F_A^(r,f).
~~~

因此，B_r是X_(r+1)的一个元素。

设N(x)=2+x(x+1)/2，并定义类型为r的BMS对角线：

~~~text
D_r(f)=Delta_r(G_(B_(n+1))^(r,f)),
~~~

其中，B_k=(0^k)(1^k)是普通的BMS种子（不是操作符B_r)。在实现中应使用不同的符号以避免这种排版冲突。

让 Pad_r(u) 替换 u 最后的数值输入 x，同时让 N(x) 保持不变，所有其他参数也保持不变。定义 a、PURE 和 BMS 为运算符。

~~~text
E_r(f)=Pad_r(D_r(f)).
~~~

它位于X_(r+1)：组成操作保持逐点顺序、单调性和扩展性。

通过 B_(x+2)[N(x)] 对 A[x] 进行显式覆盖，接着进行 (2.3) 操作，输入填充，并比较现有的种子高度，这一方法在 r 和 f 中均得到一致的结果。

~~~text
B_r(f) <= E_r(f).             (3.1)
~~~

在r=0时， E_0(f)(x)=G_(B_(N(x)+1))^(0,f)(N(x)), 早期的D_f(N(x))。 在...时候r=1这正是type-2运算符B_Theta来自hardy-root-oracle-upper.txt§6, 其中Theta扮演了f的角色。

## 4. 通过首根替换实现精确类型提升

在每种类型r下，冻结串联都是遵循的。

~~~text
F_(U⊕V)^(r,f) = F_V^(r,F_U^(r,f)).                    (4.1)
~~~

假设右侧源V。其后续迭代和极限对角线都使左侧前缀U保持冻结状态。这是整个柯里化对象的相等性，而不仅仅是一个参数上的不等式。

那么，确切的J_A基本序列恒等式则意味着

~~~text
F_(J_A(P))^(r,f) = F_P^(r+1,B_r)(f).           (4.2)
~~~

对有效载荷为P的情况进行归纳证明。 在空状态下，即P时，这个状态为B_r(f)。 在源后继Q+1处， 原始的J_A(P)[x]与x独立J_A(Q)副本。 应用 (4.1) x 次， 那么，Delta_r。 这正是在右侧层次结构中应用了I_(r+1)。 在源极限处，使用共轭J_A(P)[x]=J_A(P[x])和交换Delta_(r+1)，并将其应用于固定的f。 特殊的原始[1]并不进入x>=2的数值计算。

## 5. 对于实际C根的所有输入，都有明确的界限。

设 h=H_A 和 g=F_Lambda^BMS，那么分别得到的数值结果是 h<=g o g。精确的第一根 Hardy 结果为 H_(J_A(P))=F_P^(0,h)。反复应用 (4.2)，对于 n>=2，

~~~text
H_(S_n) = B_(n-2)(B_(n-3)) ... (B_1)(B_0)(h).        (5.1)
~~~

该应用程序保持关联状态：对于n=4，这意味着

~~~text
((B_2(B_1))(B_0))(h).
~~~

这些类型是匹配的，因为B_r属于X_(r+1)，所以B_r可以接受B_(r-1)在X_r中。

将每个B_r用其仅属于BMS的上层运算符E_r替换，使用(3.1)，并将h替换为g、o、g。每个应用都保持点序不变。因此

~~~text
H_C(x) = H_(S_x)(x)
<= [E_(x-2)(E_(x-3)) ... (E_1)(E_0)(g o g)](x),   (5.2)
x>=2.
~~~

对于x=2，右侧分别是E_0(g、o、g)(2)。对于x=3，则是E_1(E_0)(g、o、g)(3)，这与已经为S_3写下的type-2界限完全一致。(5.2)的右侧是一个明确的有限类型递归，仅使用普通的BMS基本序列、其通常的FGH、g、多项式N、逐点对角线以及函数迭代。它不包含任何原始的IBLP预言机。

## 6. 范围与剩余义务

这不是与...比较q(5). A 的 Laver-table 结构将在 (5.2) 中占据主导地位，而 TYPES 的结构则依赖于输入。 不仅仅数值的普通迭代固定次数BMS对角线g.

这也不是前往…W或者R: 最后根移植可以在执行较低上下文时复制待继续的操作。 并且不满足(4.2)。 C锥体具有简洁的首次根语法； 将那种语法扩展到更早的根源仍然有效实质性的单独问题。
