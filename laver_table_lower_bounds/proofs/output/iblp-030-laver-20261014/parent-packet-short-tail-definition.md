The expression remains a finite sequence of ordinary marked BLP. Each row contains an increasing integer for core, step size, and marks. $$
U\cup\{p+1,\ldots,p+q\},\qquad
q=|\operatorname{record}[p]|,
\tag{1}
$$

Among them, $U$ represents the original ancestor chain package, which is set to $q=0$ when there are missing parent records. The record stores the final source package after this round of completion; the formula (1) adds the target address of the parent family, not the source package itself. All insertions and marking operations are described in [A strict definition and proof of parent package propagation](<parent-packet-propagation-selector.md>). $$
\boxed{P[k]=\mathcal P\bigl(S(C^{k-2}(P))\bigr).}
\tag{2}
$$

Here, only the operations $k-2$ primary full replication, one short replication, and one finite scan are specified. There are no hidden cycles of "repeating M to the normal type." The resource constraints in implementation are merely the protection of bounded verification, and not a backtrack branch of mathematical rules; overflow should be reported as unknown and cannot be changed to cut.
