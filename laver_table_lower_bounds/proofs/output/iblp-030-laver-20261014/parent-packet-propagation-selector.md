It does not fill in the entire integer gap, nor does it reduce the unknown number of Ms into one step. ## 1. data, scanning order, and definitions

Adopt the ordinary marked BLP row type. The core of the $r$ row is $A_r$, the last item is $r$, the step size is $L_r\ge1$, and the last named point is implicitly $r+1$. Definition

$$
\delta(r)=A_r[-2],\qquad
p(r)=A_r[-L_r-1],\qquad e(r)=A_r[-L_r].
$$

A row is considered active if $L_r\ge2$ and $|A_r|\le2L_r$. Long rows and rows with $L=1$ are not considered native. The operation is performed in a left-to-right manner: each old row is processed first by freezing its old marks, and then the native operation is executed. The native new family is skipped, and it is not re-traced during the current scan.

The dictionary record is initially empty. Each time an old base line $t$ is actually inserted with $q_t>0$ new points. Record its**Final selected source package** under the key $t$. The length is $q_t$. The keys are renumbered incrementally as necessary. Synchronization explanation indicates that the current base line of the old row is used; No additional records will be registered for lines within the new family.

When processing the active row $r$, read $p=p(r),e=e(r)$ from its current core:

1. Follow the original rule along the chain from $\delta$, starting from the first jump at $e$, and collect the points that are still strictly greater than $p$.
The obtained package is written in ascending order as $U$.
2. If there is no key $p$ in the record, let $V=\varnothing$; otherwise, let
$q=|\operatorname{record}[p]|$, take

$$
   V=\{p+1,\ldots,p+q\}.
$$

3. The actual source package of native

$$
   \boxed{S=U\cup V.}
   \tag{1}
$$

Sort in ascending order, using the standard medium/short ladder formula and the same owner semantics as the native.

Here, the original address of record[p] is not included directly; what is added is the **Current target family address** $p+1,\ldots,p+q$ corresponding to this record. The two should not be confused. The theorem will prove that all $V$ points are strictly less than the current $e$. The implementation should verify this invariant, and the out-of-bounds points must not be silently removed in case of failure.

## 2. Why does record[p] point exactly to the correct parent family?

Fix the old row number for scanning the entrance. Set the entrance of the old row $v$ to p, and the entrance of the old row $w$ to $T_v,T_w$. Along the previously verified events:

- Native retains the old base line p and owner;
- Correctly retain the p/e and owner of the current owner for compTo.
- The subsequent insertion points are only numbered, while the old actual points and row identities remain unchanged.

Therefore, when dealing with the native of $v$,

$$
p(T_v)=T_w.
\tag{2}
$$

It will not unexpectedly become a new internal row of the parent family. If $w$ has $q_w$ points in this round, the key of the record is $T_w$, and its family is

$$
T_w+1,\ldots,T_w+q_w.
\tag{3}
$$

The next old $w$ is $T_w+q_w+1$. The entrance is $e(v)>w$, and since the previous compTo in this line retains the old e, the current situation is as follows.

$$
T_w+q_w<\rho(e(v))=e(T_v).
\tag{4}
$$

This proof establishes that the parent package of (1) always lies within the current $(p,e)$. If the p line does not have a native, then record[p] does not exist, and the rule naturally returns to the original ancestor package. The argument does not require that $v\to w$ is actually used by some mark; the ordinary p edges are sufficient on their own.

## 3. joint guarantee outputs ActiveSat

Definition

$$
\operatorname{ActiveSat}(P):
\quad \delta(e(r))\le p(r)\quad\text{for every active row }r.
\tag{5}
$$

For ordinary $L=1$ rows, if the core contains only $(a,r)$, then $p=a,e=r,\delta(e)=a$, and the old Sat is an identity. The remaining ordinary $L=1$ rows are long, and are not subject to the old Sat check. Therefore, in the ordinary row type domain, ActiveSat is equivalent to the original Sat for all eligible rows. This equivalence is only used after the row type is specified.

Let $S=\{s_1<\cdots<s_m\}$, and set $s_0=p,s_{m+1}=e$. A $S$ is said to cover the source gap of a $\delta$-precedes if

$$
\delta(s_{i+1})\le s_i\qquad(0\le i\le m).
\tag{6}
$$

The empty package situation is denoted as $\delta(e)\le p$. The original ancestor package $U$ satisfies the conditions: (6): The intermediate points are continuous ancestors in the iteration, and the last step crosses the threshold; when there is no package, the first jump already exceeds the threshold.

Every new point in the parent family satisfies

$$
\delta(T_w+h)=T_w+h-1\qquad(1\le h\le q_w).
\tag{7}
$$

This formula originates from the position of the continuous new target in the ordinary ladder core, and has nothing to do with whether the source package is part of an ancestral chain.

**Proof by inclusion.** $S=U\cup V$ still satisfies (6).

Proof: If the point to be checked originates from $U$ or the endpoint $e$, it was previously controlled by a previous $U$ or $p$. Taking the union only increases its immediate preceding source threshold. If it originates from $V$, the predecessor of (7) is either a point in $p$ or $V$, which is already in the union set. Therefore, all points satisfy (6).

For any such ascending source package, the ordinary native ladder satisfies at the $r+i$ row

$$
p'(r+i)=s_i,\qquad e'(r+i)=s_{i+1}\qquad(0\le i\le m).
\tag{8}
$$

The 'active' column always contains $e<r$, so the new targets inserted after $r$ do not modify the source address of the (6) query and the value of $\delta$. Thus, (6)—(8) proves that each new row satisfies ActiveSat. After processing the prefixes, they are not modified by higher rows, so the final output of a valid scan satisfies ActiveSat, without requiring the input to be originally saturated.

## 4. Each relevant upper layer packet contains the entire lower layer family as an initial segment.

Consider the internal edge $v\to w$ in the current mark's old factor chain, which is the old $p(v)=w$. If there is a packet $q_w>0$ at the lower level, §2 ensures that record[p(v)] is the correct record. If the upper level is active, the selector (1) will definitely put all the families at the lower level (3) into the current source packet.

They are the earliest consecutive integer points after p, with no other points being able to be placed in front of them. Therefore

$$
q_v\ge q_w,\qquad
u_h^{(v)}=T_w+h\quad(1\le h\le q_w).
\tag{9}
$$

The original parent package can be added after this paragraph, but it must not disrupt this initial section. From (8), corresponding to the new row having

$$
p(T_v+h)=T_w+h,\qquad J_{T_v+h}=J_v
\quad(1\le h\le q_w).
\tag{10}
$$

This is the condition for the required prefix packages for a complete marked transport, where it is not required that the total width of each layer be the same.

## The finite semantic closure of any real, ordinary input denoted by 5.

**Theorem.** Suppose the input has a true ordinary row implementation, proper accurate mark traces, and natural membership truncation semantics. According to §1, perform a parent package propagation scan, so all local operations are legal, the completion is finite, and the output still satisfies these conditions as well as ActiveSat. The global cap and the last owner remain unchanged. It is not required that the input be Sat, §Sat_rec, or derived from standard roots.

Prove by inductive reasoning along the old owner's line numbers and frozen marks. The current event only uses the proven preservation of bounds, p/e, and interval geometry from previous compTo.

The p in the ordinary row is strictly greater than its minimal term: The p in the middle row is the $L\ge2$ term; the p in the short row is the $L-1\ge2$ term, because the ordinary row type excludes the step size 2 from the short row. Therefore, each non-empty native underlying owner $K$ satisfies
$\operatorname{crit}(K)<\xi_p$.
Along the old term $W=P\circ K$, its critical points are also below the mark pairing source. Historically, natural truncation has inherited this low critical point, excluding the normal long lines that perform non-empty completion at the earliest critical-image mark. The new sources verified by compTo are below p, while the targets are at or above e.

Therefore, when the lower package is not empty, the long factor cannot pass through the current $+1$ guard: it does not have a native, and it cannot be added to the first new point from the previous compTo to $(p,e)$. The exempted $L=1$ two core points do not have proper marks, and only contain parent base points and row addresses that are later than the entire package. Similarly, they cannot pass through this guard.

Therefore, the actual execution of non-empty marks has active internal factors. By taking the common initial segment along the layers from (9)—(10) to the bottom layer width of $q$, we obtain a complete and accurate parallel p chain, with the same factor owners and all actual word images. Let the old compact posterior point of the bottom layer be $\Theta$, and the historical certificate preserved at the entrance be

$$
F\equiv_{\Delta_0}P\circ K,\qquad \Delta_0=P(\Theta).
$$

The underlying new images are $K(\xi_{u_h})<\Theta$, so the top layer corresponds to the target being satisfied

$$
(P\circ K)(\xi_{u_h})<P(\Theta)=\Delta_0.
\tag{11}
$$

Historical membership is truncated, reading all newly added F edges. The ordinary pair interval lemma is maintained for all old edges, along with the correct source/target gaps and the current p/e state. Only now is the current compTo verification completed, ready for subsequent events; there is no pre-allocated current legitimacy.

The natural world marked with the new parallel mark is $P(\xi_{T_{\rm bottom}+h+1})\le P(\Theta)$, which includes the bottom-level end $h=q$. Therefore, the natural semantics is preserved. This boundary does not require the upper family to also end here.

The $S\subset(p,e)$ selected by the native is a finite strictly ascending set; each new target is the actual image of the current owner over the corresponding source point, strictly located between the old last row point and its implicit cap. The ordinary ladder formula maintains row type, all edges, owners, and accurate direct marks. §3 assigns ActiveSat to this family.

Every entry line, every frozen mark has a limit. The ancestral chain is strictly descending, with a finite number of parent records; every native family is skipped, thus the entire scan is finite in completion. All insertions retain the old cap and last owner. This proves the theorem.

## 6. Parent prefix and original balanced BMS with retention

If the parent item is ActiveSat, a valid short copy retains its cut prefix. The scan entry record is empty. When scanning this prefix line by line, since the original ancestor package is empty and there is no native record before this, the parent package is also empty, and there is no record available for mark. Therefore, the entire old prefix remains unchanged. This argument preserves the parent cut prefix without requiring a stronger $e=p+1$.

For [Old balanced BMS ports](<../iblp-laver-bms-20261013/balanced-ribbon-bridge.md>), all its marks are empty, and every original ancestor package is also empty. The original BMS macro, when copied, remains of the same type. Therefore, the scan induction results in the record always being empty, and the selector (1) is also always empty. Thus, the original fixed-index balance single-step identity **Mathematical research manuscript** remains unchanged due to this scan replacement. The original all-index identity, if subjected to the same legal copying and guard, does not change either due to this scan replacement.

This does not mean that all unmarked inputs will remain as native. Generally, unmarked inputs can first undergo native processing, and later, another line will read their parent family, thereby filling in the gaps that were not addressed in the original ancestor chain. This section explicitly uses the invariant of the balanced band, which ensures that "no native packets are generated during the entire scanning process."

## 7. precise range

This selector retains the old BMS bands, and does not force all active replication intervals to have only one line, as is the case with fully gap-saturated scenarios. It also provides the necessary prefix packets for actual marked transport, no longer relying on the entry Sat_rec.

However, this is not yet a complete enhancement conclusion. It is still necessary to examine the comparison of the new fundamental sequences, the legal replication domains of all parameters, the strength of embedding, and the fixed index counts. In particular, multiple full copies may increase the cap, and it cannot be assumed that the entire fundamental sequence maintains a small cycle window just based on the final scan to maintain the cap. It cannot be interpreted as an increase in order type simply by adding more parent packages.
