# 一台检测 Laver 表首行周期 32 的 27 态机 · [English](README.md)

令 $q(5)$ 为普通二元 Laver 表首行周期第一次达到 32 的阶数。这里给出一台二符号图灵机，从双向无限的全零纸带启动。它**当且仅当 $q(5)$ 存在时停机**，停机时恰有 $2^{q(5)}+3$ 个 1。初态为 1，外部停机状态为 0。[完整证明](proof.zh-CN.md) · [数字转移表](transitions.txt) · [模拟器原表](machine.tm)

设 $BB$ 为最大停机步数，$\Sigma$ 为停机时能留下的最多的 1 数。每步至多新写一个 1，故只要 $q(5)$ 存在，就有

$$
BB(27)\ge\Sigma(27)\ge2^{q(5)}+3>q(5).
$$

条件结论只用普通有限表。在 ZFC + I3 中，首行周期无界保证机器停机。机器逐阶检测第 5 行第 8 列，它与第 1 行第 16 列恰在相同的阶数取零。第一次检测到非零时，算术程序已经把表宽写成了一元段。另有三个标记格，所以能读出精确产量。[表项等价与纸带不变量](proof.zh-CN.md)

## 复算有限核查

在本目录用 Python 3.10 或更高版本运行

~~~sh
python -B verification/verify.py
~~~

程序逐条核对文稿、数字表和模拟器表的 54 条指令，复验由 32 个源状态合并到 27 个工作状态的证书，再检查算术递推与纸带操作。真正从空带出发的前两个核查点在第 300 步和第 2,630 步。单独置入 $w=3$ 的测试布局时，机器在 126,983 步后停机，带上恰有 11 个 1。[核查程序](verification/verify.py) · [合并前的机器](verification/source-machine.json) · [合并证书](verification/state-groups.json) · [复算记录](verification/result.json)
